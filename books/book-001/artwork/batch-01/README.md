# Batch 01 review

Start with `facing-spreads-contact.png` and `six-bird-provisional-proof.pdf`. The proof includes the cardinal reference and all five candidates with review labels; no candidate has final approval. `original-versus-vector-contact.png` pairs each original with its trace. `QC_REPORT.md` explains the three flagged candidates and limits of automated screening. `manifest.json` links all originals, traces, hashes and source details. `MASTER_STYLE.md` and `generation-prompts.json` preserve the visual reference and the actual prompts. `REMAINING_BATCHES.md` is a proposed schedule, not authorization to generate the other 24.

To rebuild the preview in this workspace, run `PYTHONPATH=/tmp/kdp-vector-tools python scripts/build_batch1_review.py`. It uses the existing page-layout prototype and writes only batch review outputs. The relevant open-source vector tool is `vtracer==0.6.15`, installed in this session at `/tmp/kdp-vector-tools`; the existing Python environment also needs Pillow, NumPy, SciPy, PyMuPDF and ReportLab. To process one unapproved new revision, preserve the new original with a unique filename under the batch's `originals/`, record the exact prompt and source/reference provenance in `generation-prompts.json`, then run for example `PYTHONPATH=/tmp/kdp-vector-tools python scripts/process_bird_batch.py --id B02 --source books/book-001/artwork/batch-01/originals/B02-v2.png --revision v2`. Existing processed revision directories are refused rather than overwritten. `scripts/bird_prompt.py` prepares prompts from the species list and requires the master PNG to be supplied as the actual visual reference; it does not generate images.
