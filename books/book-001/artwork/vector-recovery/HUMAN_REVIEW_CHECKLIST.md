# Human review checklist — unapproved vector tests

Review each `*-comparison-print-size.pdf` at 100% / actual size with no automatic fit-to-page, plus the original and vector detail-crop sheets. A physical print is optional only if separately authorized; no proof order is implied.

For each cardinal, robin and chickadee:

- [ ] Record reviewer/date and compare shape, sex/plumage and field marks to an appropriate authoritative reference. Confirm cap/bib/cheek or mask/bill, as relevant.
- [ ] Examine head/bill, wings, feathers, feet/toe count and branch grip, tail and silhouette. Record exact correction locations; flag anything ambiguous as unresolved.
- [ ] Compare original and vector at full size for missing, fused or distorted shapes and jagged segments. Confirm intended boundaries are closed and colouring areas are accessible; check existing open branch ends.
- [ ] Measure/check the thinnest printed line at the final placed size against the externally supplied 0.75-point minimum. Review the automated thin-line warnings and avoid assuming filled paths have a uniform stroke width.
- [ ] Check margins and all edges, especially chickadee's tail and leaf, and ensure reduced image size still gives comfortable colouring space for ages 6–9.
- [ ] Check white/black contrast, no unwanted flecks, appropriate originality, no text artifacts and consistent weight across species.
- [ ] Record a decision: approve for a limited prototype, request manual correction, or REJECTED_FOR_VECTOR with a specific conversion defect. Approval requires all relevant human and technical gates; a vector-only file is not automatically accepted.

Confirm official KDP requirements and font licensing before any production release. Record review decisions in a new dated file; do not rewrite source evidence or set asset-manifest approval flags without actual human approval. Decide whether to authorize manual correction or targeted regeneration after viewing the comparison.
